# BabelLibrary · 通天塔图书馆

一个纯静态中文增量游戏：在庭院收集方向感，培养守馆青蛙，在九层书架中寻找四十枚故事片段，完成九十九层巴别试炼。原有故事文本、藏书编号和五种结局保留。

## 运行与验证

需要 Node.js 18 或更新版本，无需安装依赖。运行 `npm run dev` 后打开 http://127.0.0.1:4173 。运行 `npm test` 验证经济、战斗与页面脚本初始化，运行 `npm run build` 生成可发布的 `dist/`。也可将根目录作为静态网站使用，包括 GitHub Pages。

## 规则调整

自动收益按实际经过的时间结算，手动点击微光提供额外收益。离线收益上限为八小时。收集速度最高十级，达到每 2.5 秒一次后不能继续购买无效升级。食料升级保留速度，首次食料成本为 100，此后每次翻倍。方向感为负时收益减半，恢复非负后恢复正常；透支至负 10,000 触发迷失结局。

卡牌战斗显示敌方下次行动，防御牌保护自己，研究每三次使用可重复爆发。冷却牌不能连续使用，服务持续四回合。第 30 回合起双方受到逐渐增加的侵蚀伤害，避免无限防守。每层固定对手手牌，失败可重试；未结束的战斗会保存生命、冷却、效果、敌方意图与随机序列。

新楼层每四层出现一次骰子试炼，原存档已确定的类型保留。骰子双方公平掷出 1–20 点，率先两胜者通关；平局不计胜负，保留本金。方向感注入不改变获胜概率，可选择零投入。获胜的净收益等于投入额，落败损失投入额。通关获得 `20 + 楼层 × 5` 方向感，卡牌和骰子分别增加 5% 和 3% 的本周目光团加成。第 99 层奖励只发一次；山巅结局要求实际通关第 99 层并解锁 180 本书。

藏书首次开启收费，重读免费；书籍排列和故事位置稳定。支持触摸、键盘与可选全页照明。回溯需要确认，永久保留故事收藏与结局。

## 存档与联机

存档使用原来的 `babel_library_save` 本地存储键，并迁移旧数据。无法解析的 JSON 会先保留在 `babel_library_save_corrupt_backup`。存档只在当前浏览器和网站域名内有效；新试玩网址与原 GitHub Pages 的存档互相独立。暂不支持跨设备或多个标签页同时同步游玩。

独立联机页保留 PeerJS 点对点模式和原联机卡牌规则，修正创造牌、重复出牌、重赛状态、断线及非法数据处理。联机需要外部 PeerJS 服务与双方可连接的网络，没有提供中继服务器；此版本已进行模拟连接的规则测试，尚未通过两台真实设备进行联机验收。

## 实现

`rules.js` 与 `battle-engine.js` 是不依赖页面的规则模块，`idle.js`、`explore.js`、`combat.js`、`collection.js` 与 `ui.js` 负责状态和交互。`atelier.css` 扩展原有样式，`assets/library.webp` 为本次生成的图书馆场景插画。没有新增框架或第三方运行时依赖。Sites 的私有试玩输出由 `.openai/hosting.json` 指定。
