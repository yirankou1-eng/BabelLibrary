# BabelLibrary · 通天塔图书馆

纯静态中文增量游戏：收集方向感、培养青蛙，在九层书架中辨认四十枚故事片段，挑战九十九层巴别塔。保留原作者的深蓝视觉方向、实体书脊陈列、暗室照明玩法、故事文本、藏书编号和五种结局。

## 运行

需要 Node.js 18 或更新版本，无需安装依赖。`npm run dev` 启动 http://127.0.0.1:4173 ，`npm test` 执行自动化验证，`npm run build` 生成 `dist/`。根目录也可直接用于 GitHub Pages 等静态托管。

## 阅读与探索

书架按一整排高低错落的窄书脊陈列，在小屏幕横向滑动选书。书籍高度、颜色、编号与故事位置保持稳定，首次开启收费，重读免费。

阅读使用半径 120px 的局部光圈，光圈外完全不可见。鼠标移动或触摸拖动控制光圈；键盘方向键移动光圈，Enter 提取光圈中的句子，Esc 返回。提取点必须处于光圈的可辨认区域，且句子已被照亮至少 180ms；点击暗处不能直接收集。没有全页照明开关，聚焦也不会解除遮罩。

## 卡牌构筑与试炼

卡牌层在入塔时随机发放三张牌，没有选牌或刷新换牌。手牌会为本层锁定，失败、刷新和重新打开页面都保留同一组牌；通关进入下一层后才重新发牌。敌方手牌与下一张出牌保持隐藏，只展示已经发生的状态。

常规试炼不附加额外规则。禁书试炼让敌方生命增加 25%，光团加成额外增加 2%。缄默试炼禁止双方治疗，双方直接攻击增加 1，光团加成额外增加 1%。上述风险和收益在入塔前显示，通关不直接发放方向感。

连续打出「创造→战斗」触发破阵：战斗伤害增加 2，但清空自身剩余减伤。「学习→研究」触发求证：研究额外累积一次，同时消耗学习的下一次增伤。「教育→犯罪」触发越界：犯罪伤害增加 1，同时额外承担 1 点受伤惩罚。中间打出其他牌会打断组合；对手也适用相同组合规则。

创造牌保护自己，研究每三次使用可重复爆发。统治与学习共享两回合冷却，使用任意一张都会锁住两张牌，不能交替维持控制；玩家可以等待一回合推进冷却，但敌人仍会行动。敌人会根据生命、伤害、治疗、研究进度和状态选择行动，生命值从第 1 层的 10 点逐步增长到第 99 层接近 30 点。第 30 回合起双方受到逐渐增加的侵蚀伤害。进行中的战斗保存生命、手牌、效果、冷却、随机状态、试炼规则和组合进度。

新楼层每四层出现一次骰子试炼，旧存档已经确定的类型保留。骰子公平掷出 1–20 点，率先两胜者通关；平局重掷，不计败局。方向感注入不影响获胜概率，允许零投入；胜利净获得投入额，失败损失投入额，平局本金保留。

卡牌和骰子通关分别增加 5% 和 3% 的本周目光团加成，分支试炼在此基础上调整。战斗不直接发放方向感，强化、培养与藏书持续竞争同一笔资源。第 99 层奖励只发一次，山巅结局要求真正通关第 99 层并解锁全部 180 本书。

## 六位码联机

一人创建房间，另一人输入六位房间码加入。房间码不区分大小写，省去易混淆的 I、O、0、1，支持复制；内部通过带前缀的 PeerJS ID 定位房间，不把长连接 ID 展示给玩家。重码会自动重试，最多五次；创建与连接超过十五秒会显示超时，并允许重试。

联机保留原点对点对战规则，尚未加入单机的构筑与分支试炼。需要外部 PeerJS 信令服务和双方可连接的网络，未提供中继服务器。自动化测试模拟了六位码建房、加入、重码、无效房间、双方状态与重赛；未在两台真实设备上完成联机验收。

## 养成与存档

自动收益按实际经过的时间计算，手动微光额外提供收益，离线上限八小时。每轮速度训练共十级，从 7.5 秒缩短到 2.5 秒；本轮满级后才能进阶食料。食料进阶提升每团价值，并将速度归位到 7.5 秒，随后开启下一轮速度训练。食料首次成本 500，之后按 2.5 倍增长；速度训练成本按历史总训练次数持续增长，不能通过食料归位重置成本。负方向感期间收益减半，恢复非负后恢复正常。透支到负 10,000 触发迷失；回溯经确认后重置本周目，永久保留故事收藏与结局。

## 新手教程

新存档会自动进入五步互动教程，依次练习收集方向感、食料进阶与速度归位、暗室照明提取、随机手牌与共享冷却，以及透支和资源竞争。练习使用独立状态，不会增加方向感、解锁藏书或改动正式战斗。旧存档不会被强制弹窗，可从页首的“入馆指南”随时重学；教程进度与完成状态会保存在原存档中。

沿用 `babel_library_save` 本地存储键并迁移旧数据，损坏的 JSON 会保留在 `babel_library_save_corrupt_backup`。存档仅限当前浏览器与域名；私有试玩网址与 GitHub Pages 的存档独立，不支持多标签页同时同步游玩。

## 实现与验证

`rules.js`、`battle-engine.js`、`strategy.js`、`room-code.js` 为独立规则模块。`idle.js`、`explore.js`、`combat.js`、`collection.js` 与 `ui.js` 处理界面和状态。`atelier.css` 延续原始深蓝与抽象曲线背景，没有使用建筑插画。

测试覆盖经济循环、照明提取限制、随机手牌持久化、共享冷却、敌方决策、分支收益、连招、教程隔离、恢复存档，以及模拟双方的联机流程。构建校验静态资源和脚本语法。真实跨设备连接尚未完成验收。

PeerJS 自定义 ID 和错误事件的实现依据：[PeerJS API](https://peerjs.com/client/api/peer)。
